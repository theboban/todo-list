# Список задач

Небольшое веб-приложение на HTML, CSS и JavaScript. Добавляйте задачи, отмечайте выполненные и удаляйте ненужные. Список и отметки сохраняются в localStorage браузера после обновления страницы.

## Запуск

Откройте `dist/index.html` в браузере. Для проверки на локальном HTTP-сервере из корня проекта выполните:

```bash
python3 -m http.server 8000 --directory dist
```

Затем откройте http://localhost:8000/. Для запуска не нужны сборка и внешние зависимости.
